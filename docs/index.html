05

Running on a budget

The agent operates under a hard daily Claude API budget — $2.00/day, with $0.15 held in reserve for a guaranteed end-of-day position review, so a normal trading cycle stops itself at $1.85. Every cycle after that point is skipped entirely until the reserve kicks in near the close. The bars below are actual daily spend; the dot marks when (if at all) the day hit that wall.

Daily API spend vs. the budget cap

Dashed line at $1.85 (non-EOD cap). Hover a bar for the cap-out time, when the day hit it.

06

Guardrails at work (retired 2026-08-17)

From 2026-07-24 to 2026-08-17, every cycle screened candidates against a hard confirmation-gate rule, a same-direction concentration cap, and a proven-negative timeframe block before Claude ever got to place an order. This section tracked how often each rule actually fired. The honest result: in over three weeks live, it was zero — Claude appears to have self-filtered away from flagged candidates in its own reasoning before ever calling the trade tool, so the code path this section measures never triggered even once. All of it was removed 2026-08-17 in favor of an unconstrained-autonomy experiment (see the changelog below) — kept here as a closed, honest record rather than deleted.
